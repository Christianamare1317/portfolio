# Christian Amare — Personal Portfolio

A sleek, modern, single-page personal portfolio website built with HTML5, CSS3, and JavaScript.

🌐 **Live Demo:** [https://christianamare1317.github.io/portfolio](https://christianamare1317.github.io/portfolio)

---

## ✨ Features

- **Dark Aesthetic:** Minimalist dark slate palette with sky-cyan accent glows.
- **Fully Responsive:** Smooth layout transitions across desktop, tablet, and mobile devices.
- **Interactive Components:**
  - Responsive hamburger drawer navigation
  - Smooth scrolling with active scroll-spy link tracking
  - Interactive Python-themed hero card
  - Project showcase cards with hover lift animations
  - Technical skills progress bars with animated "Learning" indicators
  - Direct Gmail compose integration and 1-click clipboard email copying
- **Accessible & Semantic:** Structured HTML5 semantic elements with keyboard accessibility.

---

## 🛠️ Built With

- **HTML5:** Semantic markup, metadata & favicon integration
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, media queries
- **JavaScript (Vanilla):** DOM manipulation, scroll events, Clipboard API
- **Fonts:** Inter & Fira Code (Google Fonts)
